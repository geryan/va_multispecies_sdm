Selecting 200 survey points for Anopheles in Kenya

Uncertainty-weighted novelty sampling with MESS, validated with ExDet

Published

July 17, 2026

1 Summary

Large parts of Kenya have environments that are poorly represented by the existing Anopheles occurrence records, so species-distribution predictions there are extrapolated and uncertain. This report selects 200 new survey locations that best fill that gap for three vectors — An. arabiensis, An. gambiae and An. funestus — with a greedy, uncertainty-weighted novelty-sampling scheme:

  • Novelty is measured with MESS (the Multivariate Environmental Similarity Surface): how far each pixel’s environment falls outside the covariate ranges seen at existing records.
  • Uncertainty is the per-pixel coefficient of variation (CV) of the current distribution models.
  • Each iteration adds the single most-novel × most-uncertain unsampled pixel, shared across all three species, then recomputes — so the whole set is built around common points.

The 200 points, in priority order, are exported to k_m_r_selected_points.csv. An independent metric (ExDet) confirms the design eliminates univariate environmental novelty within the first ~16 points and then steadily reduces the harder combinational novelty.

  absmax <- max(abs(unlist(lapply(

3 Measuring environmental novelty (MESS)

MESS compares each pixel’s covariates to the range of values in the reference set (the occurrence records):

  • Positive (blue) — similar to the reference; the pixel sits inside the observed covariate ranges.
  • Negative (red) — novel; the pixel falls outside the observed range of at least one covariate, so a model trained on the reference set is extrapolating.
  • Near zero (white) — at the edge of the observed environmental space.

The baseline (iteration 0) surfaces below use each species’ own records. Note how similar the three are: the novel (red) regions fall in the same places, so a single shared set of survey points serves all three species.

4 The selection method

A single shared point is chosen each iteration and added to every species’ reference set, so all three evolve around common locations. Two features define the search:

  1. Weighted by uncertainty. The selection surface is MESS × CV, so the pick is the pixel that is both environmentally novel (strongly negative MESS) and poorly constrained by the current models (high CV). Across species, each pixel is driven by its most-dissimilar species.
  2. Distinct cells. Once a pixel is chosen it is masked out, forcing a new location every iteration. This matters after novel space is used up: otherwise the search re-picks the same near-zero pixel repeatedly, instead of spreading points to improve coverage.

Selection runs in two phases, tracked for reporting only (the criterion never changes): a novelty phase while any pixel is still novel (negative MESS somewhere), then a coverage phase once every pixel is inside the envelope.

5 Running the selection

The loop below does everything in one pass. At each iteration it holds the reference set (records + points chosen so far) and, for every species,

  • computes MESS (drives the pick and the objective trajectory), and
  • computes ExDet (the independent validation metric, §6),

recording per-iteration totals and keeping every iteration’s surface (the rasters are small). It then selects and adds the next shared point. The evolution grids below just pick 9 evenly-spaced iterations out of the full history.

code 
n_points   <- 200
grid_iters <- round(seq(0, n_points, length.out = 9))  # 9 iters shown in grids

ref_vals     <- ref_vals_0        # grows as points are added (shared)
chosen_cells <- integer(0)        # grid cells already selected (kept distinct)

selected_points <- data.frame(
  longitude = numeric(0), latitude = numeric(0),
  source_species = character(0), iteration = integer(0), phase = character(0)
)

# Per-iteration scalar trajectories, summed over all cells and species.
traj <- data.frame(
  iteration   = 0:n_points,
  total_mess  = NA_real_,   # sum of MESS (the objective)
  exdet_type1 = NA_real_,   # sum |exdet| where exdet < 0  (univariate novelty)
  exdet_type2 = NA_real_    # sum (exdet - 1) where exdet > 1 (combinational)
)

# Keep every iteration's surface, per species (the rasters are small). Indexed by
# iteration: [[sp]][[i + 1]] is the surface after i points have been added.
mess_surfaces  <- setNames(lapply(ken_mess_spp, \(s) vector("list", n_points + 1)), ken_mess_spp)
exdet_surfaces <- setNames(lapply(ken_mess_spp, \(s) vector("list", n_points + 1)), ken_mess_spp)

novelty_exhausted       <- FALSE
novelty_exhaustion_iter <- NA_integer_

for (i in 0:n_points) {

  # MESS (selection + objective) and ExDet (validation) for every species.
  mess_i  <- setNames(lapply(ref_vals, \(rv) mess(cov_rast_ken_sub, rv)$mess),  ken_mess_spp)
  exdet_i <- setNames(lapply(ref_vals, \(rv) exdet(cov_rast_ken_sub, rv)$exdet), ken_mess_spp)

  mess_vals  <- lapply(mess_i,  \(r) values(r)[, 1])
  exdet_vals <- lapply(exdet_i, \(r) values(r)[, 1])
  traj$total_mess[i + 1]  <- sum(sapply(mess_vals,  \(v) sum(v, na.rm = TRUE)))
  traj$exdet_type1[i + 1] <- sum(sapply(exdet_vals, \(v) sum(abs(v[v < 0]), na.rm = TRUE)))
  traj$exdet_type2[i + 1] <- sum(sapply(exdet_vals, \(v) sum(v[v > 1] - 1,  na.rm = TRUE)))

  for (sp in ken_mess_spp) {
    mess_surfaces[[sp]][[i + 1]]  <- mess_i[[sp]]
    exdet_surfaces[[sp]][[i + 1]] <- exdet_i[[sp]]
  }

  if (i == n_points) break

  # Selection surface: MESS x CV, most-dissimilar species drives each pixel;
  # already-chosen pixels are masked so every pick is distinct.
  sel_cols <- setNames(lapply(ken_mess_spp, \(sp) values(mess_i[[sp]] * cv[[sp]])[, 1]),
                       ken_mess_spp)
  cell_min <- do.call(pmin, c(sel_cols, na.rm = TRUE))
  cell_min[chosen_cells] <- NA
  if (all(is.na(cell_min))) { message("All cells chosen at iter ", i); break }

  sel_cell <- which.min(cell_min)                                   # global pick
  sp_name  <- ken_mess_spp[which.min(sapply(sel_cols, \(v) v[sel_cell]))]

  # Phase bookkeeping: novelty until no negative MESS remains anywhere.
  if (!novelty_exhausted && min(sapply(mess_vals, \(v) min(v, na.rm = TRUE))) >= 0) {
    novelty_exhausted <- TRUE
    novelty_exhaustion_iter <- i
  }

  xy <- xyFromCell(mess_i[[sp_name]], sel_cell)
  selected_points <- rbind(selected_points, data.frame(
    longitude = xy[1, "x"], latitude = xy[1, "y"], source_species = sp_name,
    iteration = i, phase = if (novelty_exhausted) "coverage" else "novelty"
  ))
  chosen_cells <- c(chosen_cells, sel_cell)

  # Add the chosen point to every species' reference set.
  new_vals <- terra::extract(
    cov_rast_ken_sub,
    vect(data.frame(x = xy[1, "x"], y = xy[1, "y"]), geom = c("x", "y"),
         crs = crs(cov_rast_ken_sub)),
    ID = FALSE
  )
  for (sp in ken_mess_spp) ref_vals[[sp]] <- rbind(ref_vals[[sp]], new_vals)
}

cat(sprintf("Selected %d distinct points.\n", nrow(selected_points)))

6 Results

6.1 Novelty is reduced as points are added

The objective — total MESS summed over every pixel and species — rises steeply as the strongly-novel pixels are absorbed and the covariate envelope widens to cover them (dashed line: novelty exhausted, no negative MESS left anywhere). Gains continue past that point: each distinct new pixel keeps shifting the reference distribution and pulling more area toward higher similarity, so the full 200-point budget does useful work. The climb is not strictly monotonic — the criterion picks the most-dissimilar pixel, not the one that maximises the sum — but the trend is clearly upward.

7 Validation with ExDet

MESS drives the selection, so it is not an independent check. ExDet (Extrapolation Detection) is a second, richer novelty metric computed on the same growing reference set (already recorded in the loop above). It splits novelty into two kinds, encoded in a single value per pixel:

  • exdet < 0 — Type 1 (univariate): outside the observed range of at least one covariate. This is the same regime MESS flags as negative.
  • 0 ≤ exdet ≤ 1 — similar: in range univariately and inside the combinational (Mahalanobis) envelope.
  • exdet > 1 — Type 2 (combinational): every covariate is individually in range, but their combination is novel.

7.1 Novelty trajectories

Type 1 novelty collapses to zero within the first ~16 points (grey dotted line): each extreme point widens some covariate’s observed range, quickly bringing every pixel univariately in-range — exactly what the MESS objective is driving.

Type 2 novelty only wobbles while Type 1 is still collapsing (all the movement is left of the grey line), then settles into a slow decline. It never reaches zero: combinational novelty is much harder to eliminate than univariate novelty, so some pixels remain novel combinations even after 200 points.

NoteWhy Type 2 rises before the grey line (an ExDet artefact, not created novelty)

A pixel reports its ExDet score as ifelse(nt1 == 0, nt2, nt1), so while it is univariately novel its combinational novelty is masked; as Type 1 collapses, those pixels reveal their Type 2 values and swell the sum. On top of that, nt2 = mahalanobis / mah_max is normalised by the most-extreme reference point, so adding an extreme point transiently inflates mah_max and rescales the whole surface. Both effects are active only while the reference set is univariately unsaturated — i.e. left of the grey line — after which Type 2 declines cleanly.
